# clanker-pack

Personal Claude Code plugin marketplace.

## Usage
```
/plugin marketplace add Iah-Uch/clanker-pack
/plugin install senior-pack@clanker-pack
/plugin install ui-pack@clanker-pack
/plugin install quality-pack@clanker-pack
/plugin install tools-pack@clanker-pack
/plugin install stack-pack@clanker-pack
```
